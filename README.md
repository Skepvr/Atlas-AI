# Atlas AI – Image Assets

Atlas AI is a private AI assistant that runs locally on your computer using [Ollama](https://ollama.com).

This folder contains the official branding and image assets for Atlas AI, including application icons, high-resolution logos, and social media preview graphics.

## 📁 Image Files

| File | Dimensions | Format | Purpose |
|---|---:|---|---|
| `atlas.ico` | 256 × 256 | ICO | Windows application icon |
| `atlas.icns` | 1024 × 1024 | ICNS | macOS application icon |
| `atlas-256.png` | 256 × 256 | PNG | Small application icon |
| `atlas-1024.png` | 1024 × 1024 | PNG | High-resolution application icon |
| `social-preview.png` | 1280 × 640 | PNG | GitHub and social media preview |
